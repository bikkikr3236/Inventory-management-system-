# 📦 Inventory Management System

A modern **Inventory Management System** built with **Java (Swing)** and **MySQL**. This desktop application helps small and medium-sized businesses efficiently manage products, customers, suppliers, sales, purchases, and inventory.

## 🚀 Features

- 🔐 Secure Login System
- 📦 Product Management
- 📊 Inventory & Stock Tracking
- 👥 Customer Management
- 🚚 Supplier Management
- 💰 Sales Management
- 🛒 Purchase Management
- 👨‍💼 User Management (Admin Only)
- 📜 User Activity Logs
- 🔍 Fast Search Functionality
- ⚡ Automatic Stock Updates

## 🛠️ Tech Stack

- Java
- Java Swing
- JDBC
- MySQL
- IntelliJ IDEA / NetBeans

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/Inventory-Management-System.git
```

2. Open the project in IntelliJ IDEA or NetBeans.

3. Import the MySQL database.

4. Update your database credentials.

5. Run the project.
